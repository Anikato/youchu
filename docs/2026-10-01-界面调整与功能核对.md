# 界面调整与功能核对

本轮继续家庭物品管理方向，不改变数据库结构。

## 已调整

- 移到回收站后同时刷新分类与回收站缓存。
- 删除照片、永久删除物品时，文件清理失败使用标准库 slog 记录照片 id 和错误；保持现有响应语义。
- 浅色与深绿主题、桌面内容区加宽、物品卡片、无照片占位、结果数量、分区表单和折叠筛选样式。
- 手机底部四入口导航、底部安全区、较大触控目标、长名称与位置换行、16px 输入文字。

## 需求覆盖

| 需求 | 当前实现 |
| --- | --- |
| 最少只填写名称，同名记录 | 已实现 |
| 区域、固定储物位、移动盒子及编号 | 已实现，沿用现有位置类型规则 |
| 移动盒子后路径更新 | 已实现，路径读取时计算 |
| 一物多位置及分放备注 | 已实现 |
| 多分类、分类层级、按分支筛选 | 已实现 |
| 名称、别名、型号、备注关键词搜索 | 已实现包含匹配，不支持错字纠正或自然语言语义 |
| 查看位置或容器内物品 | 已实现直接物品列表和下级位置 |
| 待定位、归位事项、保留正式位置 | 已实现 |
| 照片、回收站、恢复 | 已实现 |
| 单独登记配件并关联主体 | 目前只能用备注表达，没有物品间关系功能 |
| AI 分类、报告、问物品在哪 | MCP/认证仍待实现 |
| 主动通知 | 未实现，原需求尚未确定 |
| 手机与电脑使用 | 已做响应式布局，完整交互验收待完成 |

## 本轮验证

- go test ./... -count=1 通过。
- web 内 npm run build 通过。
- 浏览器登录页在 390×844、320×740 没有横向溢出；390 宽时输入框约 50px 高，登录按钮约 46px 高。
- 独立临时数据目录 /tmp/youchu-ui-review-20261001。环境禁止 Go 服务监听 127.0.0.1:8080，故本轮不能完成登录后的实际浏览器验收。不能据此声称所有页面已通过手机验收。
