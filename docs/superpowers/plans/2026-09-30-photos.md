# 照片 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给已保存的物品加 JPEG/PNG/WebP 照片，转成原图加缩略图落盘，列表用第一张缩略图，永久删除时清掉该物品自己的文件。

**Architecture:** `migrations/005_photos.sql` 建 `photos` 表。`internal/photo` 识别格式、转正、缩放、写 `originals/` 与 `thumbnails/`。`internal/catalog` 管行、顺序、20 张上限和 JSON 字段。`internal/httpapi` 先处理 Origin、会话、multipart/JSON，再调用上述两包。读图走已登录的 `/api/v1/photos/{id}/thumbnail|original`。网页不新增依赖。

**Tech Stack:** 现有 Go 1.27.1、`modernc.org/sqlite` v1.60.1、React 19.3.0、Vite 8.3.1、TypeScript 7.0.2、React Router 8.4.0、TanStack Query 5.104.0。允许新增纯 Go 模块 `golang.org/x/image`（WebP 解码、缩放）和 `github.com/rwcarlsen/goexif`（JPEG Orientation）。不启用 CGO，不新增 npm 包，不新增环境变量。

规格：`docs/superpowers/specs/2026-09-30-photos-design.md`。

提交：本目录还不是 Git 仓库。每个提交步骤先检查 `git rev-parse --is-inside-work-tree`。不是仓库就跳过 commit，**不要** `git init`。有仓库但没有 `user.name` 就停下来问用户，不要改 Git 配置，也不要编造作者。不要提交 `/data/`、`web/node_modules/` 或 `web/dist/`。

- [ ] **Step 3: 实现识别、转码、落盘**

`Detect(header []byte) error`：按规格 5.1 的魔数。HEIC/HEIF（`ftyp` brand / compatible 含规格列出的四字符）返回 `ErrHEIC`。JPEG/PNG/WebP 返回 nil。其它返回 `ErrNotImage`。

`Transcode(src []byte) (Result, error)`：

1. `Detect`
2. `image.DecodeConfig`；`int64(w)*int64(h) > MaxPixels` 或边小于 1 → `ErrTooManyPixels`
3. 空白 import `image/jpeg`、`image/png`、`golang.org/x/image/webp`
4. `image.Decode`；再检查实际像素
5. JPEG 用 `goexif` 读 Orientation 2–8，转正像素（2 镜像、3 180、4 垂直镜像、5–8 90° 组合）
6. PNG/WebP 不读方向
7. 有透明通道则铺白底
8. 长边 > 4096 则用 `golang.org/x/image/draw` 等比缩小到 4096
9. `jpeg.Encode` 质量 85 得到原图字节；再从该位图做长边 `min(400, 长边)` 的缩略图
10. 输出不得再带 Orientation 2–8

`Place(dataDir string, id int64, original, thumb []byte) error`：写入 `tmp/` 下唯一文件名，再改名为 `originals/{id}.jpg` 与 `thumbnails/{id}.jpg`。两份都成功才返回 nil；失败则删除本次 tmp 和已改名文件。

`Remove(dataDir string, id int64) error`：删两份最终文件，`os.IsNotExist` 视为成功。
