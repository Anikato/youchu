# MCP 与个人访问令牌 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 账号页签发可撤销的个人访问令牌，Go 进程在 `/mcp` 提供 Streamable HTTP，工具直接调用现有目录，归类只追加 AI 关联。

**Architecture:** 迁移 `006` 建 `access_tokens` 并为 `item_categories` 增加 `source`。`internal/auth` 管令牌哈希。`internal/catalog` 管 `source` 与 AI 归类追加/删除。`internal/mcp` 用官方 Go SDK 注册工具，不向本进程发 HTTP。`internal/httpapi` 给令牌 CRUD 和 `/mcp` 做 Cookie/Origin 或 Bearer。网页只在账号页管令牌。

**Tech Stack:** 现有 Go 1.27.1、`modernc.org/sqlite` v1.60.1、React 19.3.0、Vite 8.3.1。新增 `github.com/modelcontextprotocol/go-sdk` v1.8.0。不启用 CGO，不新增 npm 包，不新增环境变量。

规格：`docs/superpowers/specs/2026-10-01-mcp-auth-design.md`。

提交：本目录还不是 Git 仓库。每个提交步骤先检查 `git rev-parse --is-inside-work-tree`。不是仓库就跳过 commit，**不要** `git init`。有仓库但没有 `user.name` 就停下来问用户，不要改 Git 配置，也不要编造作者。不要提交 `/data/`、`web/node_modules/` 或 `web/dist/`。

- `internal/httpapi/token_http.go`：令牌 HTTP。写失败顺序 Origin → 会话 → 正文/查询 → 字段 → 上限/存在。
- `internal/mcp/server.go`：SDK 服务器、工具注册、`Handler()`。
- `internal/mcp/authctx.go`：把令牌放进 `context`。
- `internal/httpapi/mcp_http.go`：`/mcp` Origin 规则 + Bearer，然后交给 SDK。

- `web/src/pages.tsx`：账号页接入令牌区块。
- `web/vite.config.ts`：代理 `/mcp`。
- `README.md`、`docs/工作记录.md`。

令牌写接口正文上限 4096。`writeFields` / `queryRejected` / `accountWrite` 同包可复用 Origin+会话骨架，但 DELETE 令牌不读正文。不要把 MCP 认证接到 Cookie。

func mcpPost(h http.Handler, token, origin, body string) *httptest.ResponseRecorder {
	req := httptest.NewRequest(http.MethodPost, "/mcp", strings.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Accept", "application/json, text/event-stream")

	}
	if token != "" {
