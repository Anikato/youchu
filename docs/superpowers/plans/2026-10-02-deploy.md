`server.go`：`handler` 增加 `web fs.FS`。`New` 调用 `newHandler(..., webui.Dist)`。`newHandler` 创建 mux，把 `mux.HandleFunc("/", h.spa)` 代替原来的 `notFound`。

`spa`：

- `/api` 或 `/api/` 前缀 → `notFound`
- `/mcp` 或 `/mcp/` 前缀 → `notFound`（`/mcp` 本身已被更具体的 Handle 接住）
- 方法不是 GET/HEAD → `notFound`
- `index.html` 打不开 → `notFound`
- `path.Clean("/" + r.URL.Path)` 后去掉开头 `/` 得到相对路径；`"."` 当作 `index.html`
- `fs.Stat` 成功且不是目录 → `http.FileServer(http.FS(h.web)).ServeHTTP`（或 `http.ServeContent`）
- 相对路径的最后一段含 `.` → `notFound`
- 否则读 `index.html`，`Content-Type: text/html; charset=utf-8`，200 写出

embed 的 FS 根是 `.`，文件在 `dist/index.html`。`webui.Dist` 的路径带 `dist/` 前缀。`newHandler` 里若能 `fs.Sub(web, "dist")` 则 sub，失败则直接用传入的 FS（测试 MapFS 根上就是 `index.html`）。

```go
func webRoot(web fs.FS) fs.FS {
	if web == nil {
		return nil
	}
	sub, err := fs.Sub(web, "dist")
	if err != nil {
		return web
	}
	if _, err := fs.Stat(sub, "index.html"); err == nil {
		return sub
	}
	if _, err := fs.Stat(sub, ".gitkeep"); err == nil {
		return sub
	}
	return web
}
```

测试 MapFS 没有 `dist/` 子目录，`fs.Sub(web, "dist")` 对 MapFS 可能仍返回一个空 sub。务必：Sub 之后若既没有 `index.html` 也没有其它文件，回退到原 FS。对 embed：Sub("dist") 后有 `.gitkeep` 或 `index.html`。

更稳：

```go
func webRoot(web fs.FS) fs.FS {
	if web == nil {
		return nil
	}
	if _, err := fs.Stat(web, "index.html"); err == nil {
		return web
	}
	if sub, err := fs.Sub(web, "dist"); err == nil {
		return sub
	}
	return web
}
```

无 `index.html` 时 `spa` 走 JSON 404。embed 默认没有 index，本机 `GET /` 仍 404。Docker 拷入 index 后生产 200。
