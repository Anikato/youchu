按用户已确认设计连续实施，在当前工作目录保留所有既有文件，不做 Git 写操作。工具目录没有 update_plan，使用下表记录阶段，保持一个 in_progress。

核心行为检查：整件未归位与部分配件未归位分别标记；位置搜索按完整路径匹配且精确编号优先；树使用 parent_id 关联而不依赖 id 顺序；列表返回保留 URL 条件；阅读页不包含资料编辑输入；位置含下级采用已有 in_location 参数；动画不在页面壳保留 transform。

## 验收记录

使用独立临时数据库与端口 18080/15173，未读取或修改生产数据，未部署。浏览器验证了 390px 手机布局和 1280px 桌面布局；手机首条物品约在 421px 处出现，固定保存栏与底部导航不重叠，桌面无横向溢出。

已验证位置树、包含下级/仅直接存放、名称单字段连续录入、保存后进入阅读页、搜索→阅读→编辑→阅读→返回保留条件。以一张正常图片和一张无效图片验证部分上传失败及重试，数据库确认只创建一件物品、成功图片没有重复。会话失效提交会稳定回到登录页。代码复核未发现重要未解决问题。

构建仍提示主 JS 包超过 500kB。真实手机相机、Safari 和生产数据规模尚未实测；失败图片暂存在当前标签页内存，刷新或关闭前需要重试或明确放弃。
