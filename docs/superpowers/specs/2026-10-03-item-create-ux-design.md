# 有处：添加物品体验

日期：2026-10-03

状态：已实现。

依据：分类搜索、照片、家用界面、PWA 拍照规格。冲突时，照片仍是物品建成后再 `POST`；本文件覆盖新增/编辑页反馈、上次位置、手机贴底保存、列表排序。

## 1. 目标

在手机 PWA 上连续登记物品时：看得见成没成、位置不用每次重找、保存按钮不用滑去找、拍照有预览和进度、列表最新在前。

## 2. 不做的事

位置下拉不改成搜索。不做按分类排序。不在浏览器里压缩照片。不改照片 POST、不改 HEIC、没有新表、没有新环境变量。Playwright 不进仓库。

## 3. 新增物品保存之后

成功（含照片传完）留在 `/items/new`。名称和待传照片清空。位置和分类保留。焦点回到名称。一句「已保存：{名称}」，链到 `/items/{id}`。

部分照片失败：仍留在新增页，名称和待传照片清空，位置分类保留。提示「已保存：{名称}，有照片没传上」，链到该物品页补图。

把这次保存成功的位置 id、分类 id 写入 `localStorage`（`youchu-last-location-id`、`youchu-last-category-ids`）。下次打开新增页、地址没有 `location`/`category` 时，若这些 id 仍存在就预填。地址带 `location` 或 `category` 时，对应那一项用地址，不用上次的。

## 4. 提示与手机保存条

新增和编辑物品：保存成功或失败都有可见提示。失败时滚到第一个出错字段。

宽度 ≤640px：主保存按钮贴在底栏导航上方，键盘弹出时跟着抬。文案：空闲「保存」；正在建物品「保存中」；正在传照片「上传 {当前}/{总数}」；刚成功「已保存」。表单里原来的保存按钮在这个宽度下隐藏。桌面仍用表单内按钮。

编辑页保存成功留在本页，提示「已保存」。

## 5. 照片

新增页待传文件显示缩略图，可单张去掉。未点保存前不上服务器。名称非空或还有待传照片时，离开本页（底栏、返回、关页）先问「尚未保存，要离开吗？」。离开则丢掉本地文件。

编辑页添加照片时显示正在上传。

## 6. 物品列表排序

`GET /api/v1/items` 增加 `sort`，最多一次。

| 值 | 顺序 |
| --- | --- |
| 省略或 `created_at` | `created_at DESC, id DESC` |
| `name` | `name, id`（与改之前默认相同） |

其他值或出现两次：`fields.sort`「不支持的参数」。回收站列表顺序不变。

网页默认最新在前（地址栏省略 `sort`）。可改「按名称」，写入 `sort=name`。改排序时去掉 `offset`。卡片显示相对添加时间：一分钟内「刚刚」，一小时内「N分钟前」，一天内「N小时前」，更早用日期。

MCP `youchu_search_items` 增加可选 `sort`，语义相同。

## 7. 测试

- 默认列表新的在前；`sort=name` 按名称；非法 `sort` 为 400。
- `cd web && npm run build`。
- 浏览器：新增物品保存后仍在新增页、有「已保存」、位置还在；列表最上是刚加的；390 宽保存条在底栏之上。
