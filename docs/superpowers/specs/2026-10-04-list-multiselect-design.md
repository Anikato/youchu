# 有处：列表多选与物品分页

日期：2026-10-04

状态：已实现。

依据：删空盒子要一次勾多条；物品和位置都要多选；删除要确认、能撤销；首页物品要选每页条数并看到页数；勾选物品可搬家到一个位置；待归位可批量完成。用户选定：只勾当前页；点「选择」才出现勾选；占用中的位置不能勾；搬家清掉原来的位置；位置撤销用短时「撤销」条。其余按推荐。

## 1. 目标

在现有列表里勾当前页的记录，做删除、恢复、搬家、完成归位。首页物品列表能改每页条数，并显示第几页、共几页。

## 2. 不做的事

没有新的批量 HTTP 路径。没有位置回收站。没有跨页勾选。分类列表不做多选。回收站不做批量永久删除。完成归位没有撤销。没有新表、没有新环境变量、没有新 npm。Playwright 不进仓库。不改 MCP 工具清单（位置 JSON 多一个 `child_count` 字段）。

## 3. 进入与范围

物品首页、位置首页、某个位置的子位置、某个位置里的物品、某个分类下的物品、回收站列表、待归位列表：右上或该段标题旁有「选择」。点了才出现勾选框，按钮变成「完成」。点「完成」退出并清空勾选。

勾选只对当前这一页有效。改页、改每页条数、改筛选会清空勾选。占用中的位置（`child_count > 0` 或 `direct_item_count > 0`，含回收站占用）没有可勾的框，名称仍可点进详情。

「本页全选」只勾本页允许勾的行。选择模式下点可选行是勾选，不进详情。

## 4. 各页动作

确认文案出现在底部操作条里，要再点一次才执行。请求按勾选顺序一条一条发，用现有接口和该行的 `version`。

- 物品（首页、位置里、分类下）：「移到回收站」→ `DELETE /api/v1/items/{id}?version=`；「放入位置」先搜选一个位置，确认后 `PATCH /api/v1/items/{id}`，正文带 `version`、`name`（该行原名）和 `locations: [{ location_id }]`，原来的存放全部清掉。
- 位置（首页、子位置）：「删除」→ `DELETE /api/v1/locations/{id}?version=`。只能勾空位置。
- 回收站：「恢复」→ `POST /api/v1/trash/{id}/restore` 带 `version`。
- 待归位：「完成归位」→ `POST /api/v1/return-tasks/{id}/complete` 带 `version`。没有撤销。

部分失败继续做剩下的，结束后提示「成功 n，失败 m」和失败原因。成功的那些保留。

## 5. 撤销

只针对删除。横幅在本页，约 10 秒后消失；离开本页即没了。

- 物品：横幅「已将 n 件移到回收站」，点「撤销」对刚删成功的 id 用 `version+1` 调恢复。物品本来也在回收站里，可随时进回收站恢复。
- 位置：横幅「已删除 n 个位置」，点「撤销」按删除前的名称、类型、编号、父级、图标、自传图标 `POST /api/v1/locations` 建回来（新 id）。编号被占用则那一条失败并写进提示。

搬家、恢复、完成归位没有这条横幅。

## 6. 物品分页

只在物品首页。每页条数下拉：30、50、100。默认 30，此时地址栏不写 `limit`。50 或 100 写入 `limit`。改条数时 `offset` 回到 0。API 已有 `limit`（1–100）。

分页条在有记录时显示「第 x / y 页」，不够一页也显示「第 1 / 1 页」。有上一页、下一页时仍显示这两个按钮。其它列表共用这个页码文案，不改它们的每页条数。

## 7. `child_count`

`GET /api/v1/locations` 与 `GET /api/v1/locations/{id}`（以及 MCP 同一份位置 JSON）增加整数 `child_count`：`parent_id` 等于该位置的子位置条数。物品占用仍只看 `direct_item_count`。没有新查询参数。

## 8. 测试

- `child_count`：新建为 0；有一个直接子位置为 1；孙级不算进祖级；物品占用不加 `child_count`；列表和详情都有这个字段。
- `readItemList` / `writeItemList`：默认不写 `limit`；`limit=50` 和 `100` 往返；其它 `limit` 当 30。
- `pageIndex` / `pageCount`：30 条 1 页；31 条 2 页；offset 30 且 limit 30 是第 2 页。
- `locationDeletable`：子位置或物品占用都不可删。
- `cd web && npm run build`。
- 浏览器：物品首页改每页 50 并看到页码；选择后勾两条进回收站，撤销后回来；位置页空盒子可勾、有格子的九抽盒不可勾；待归位选择后批量完成。
