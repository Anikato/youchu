# 有处界面改版

用户已确认整体改版，按推荐方向直接实施。保留 API、数据结构、版本冲突、多位置、分类来源、照片和回收站规则。禁止新增依赖、提交、推送、建分支和生产写入。

## 页面与视觉

- 桌面深绿侧栏、浅色纸面内容区，手机顶部品牌和底部四入口；旧主题偏好保留，无偏好时使用浅色。
- 紧凑列表、明确编号、状态标签、统一按钮/表单/反馈；取消页面壳的位移动画，固定栏不受 transform 影响。
- 首页搜索优先，排序/每页与复杂筛选收起。卡片显示全部位置、型号、未完成归位。搜索同时显示匹配的位置，编号精准匹配排前。
- `/items/:id` 默认阅读，`/items/:id/edit` 编辑；阅读显示照片、位置链接、分放备注、归位操作和资料，支持一物多位置。
- 位置首页支持全屋搜索与展开树。位置详情默认含下级物品，可切直接存放；管理表单折叠。
- 分类首页支持树浏览与搜索；新建物品分类和放置备注渐进展开，保留连续录入和预设位置。
- 照片失败保留文件并重试已有物品，批量错误保持可见，登录网络错误可重试。
